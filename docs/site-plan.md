# 2. Plan the pages

<DocReview id="PLAN" />

Our website should help someone understand the brand, learn about the shirt, and try a pretend purchase.

## Start with a small website

| Page | What belongs there |
| --- | --- |
| **Home** | A strong photo, our brand message, and a button to see the shirt. |
| **The Shirt** | Photos, sample price, fit and size information, size and quantity choices, and an Add to bag button. |
| **Our Story** | Why the brand exists and who it is for. |
| **Bag** | Selected shirts, quantities, a total, and a button for demo checkout. |
| **Demo checkout** | Fictional sample details and a button to place a pretend order. |
| **Confirmation** | A clear message that the order was a demo, plus a summary. |

For the first version, we can include a few outfit photos and one useful styling guide on the main pages. A separate lookbook and more articles can wait.

## Walk through a purchase

**Home → The Shirt → Choose a size → Add to bag → Demo checkout → Confirmation**

Visitors should also be able to change their bag or return to the shirt page. Buttons should clearly describe what happens next.

## Help people find and share it

- Give each public page a clear title and description.
- Write useful text about fit, styling, and care, using verified facts.
- Use descriptive image text for people who cannot see a photo.
- Make pages work well on phones and load quickly.
- Set a title, description, and image for shared links.

Later, we’ll add a sitemap—a list of public pages for search engines—and check indexing with Google Search Console. Bag and checkout pages should stay out of search results.

## Keep the design simple

Use readable text, clear buttons, good contrast, and consistent spacing. Visitors should be able to use the site with a keyboard. Choose photos, colors, and fonts after we agree on the brand.

## Discuss these three questions

1. Is this enough for the first version? What can we leave out?
2. What information would you need before choosing a shirt?
3. What should the site feel like on a phone?
