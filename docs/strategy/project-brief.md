# Project brief

<DocReview id="BRIEF" />

## Purpose
Create an educational brand experience around one plain white T-shirt. Write and review specifications before implementing a static storefront.

## Confirmed constraints
- Storefront: Vite, HTML, CSS, and JavaScript.
- Hosting: GitHub Pages; no runtime backend.
- Checkout: simulation only; no real orders or payments.
- Documentation: VitePress in the same repository, reviewed through linked GitHub issues.

## Proposed success measures
Visitors can explain the brand promise, evaluate the shirt, choose a size, and complete the demo flow. Reviewers can follow a requirement from specification to issue, pull request, and verification evidence. Numerical targets await agreement.

## Scope
This phase delivers documentation and the review workflow. Proposed storefront scope includes Home, The Shirt, Our Story, Lookbook, useful guides, and a demo cart and checkout.

## Outside current scope
Real commerce, customer accounts, payment collection, inventory services, and email collection.

## Review questions
Is the proposed page scope appropriate? Who is the primary audience? What evidence will demonstrate a successful brand experience?
